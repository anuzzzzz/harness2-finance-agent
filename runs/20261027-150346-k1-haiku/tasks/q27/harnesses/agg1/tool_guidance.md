# Tool use

- Decide the document and period before searching: company, form (10-K), fiscal year, and the section that governs the question (for debt terms, the debt / capital structure note plus the MD&A capital-resources discussion). Use edgar_search with the company CIK and date filters, not the question's wording. Never issue a web_search with an empty or null query. If web_search returns nothing, retry once with a short non-empty query, then use edgar_search or a known URL.
- A search snippet or result title is a lead, not evidence. Open the primary filing with parse_html_page (one clear key), then ask retrieve_information one targeted question at a time. Use input_character_ranges on long filings (debt notes sit late in the document). Confirm each term, its period and its units in the retrieved text. parse_html_page cannot read PDFs; use the HTML filing.
- "Terms of" questions: retrieve every term the filing states for the instrument (amount outstanding with prior year, coupon and reset benchmark/spread, scheduled and final maturity, call/redemption, interest deferral and compounding, stock-issuance obligations, dividend restrictions during deferral, replacement-capital covenant, ranking). Keep it separate from similarly named instruments (Subordinated Debentures are different from Junior Subordinated Debentures). If the filing is silent on a term, say "not stated" rather than inferring it.
- Re-check each figure against the retrieved text before submitting. Submit with submit_final_result while budget remains.
- Cite only documents you opened and retrieved from. Do not list pages seen only in search results (press releases, annual-report PDFs, rating-agency notes, spreadsheets). Write the answer in plain text with no citation markup such as <cite> tags, and end it with the sources dictionary the system prompt requires.
