# Tool use

- Decide the documents and periods before searching: company, form (8-K EX-99.1 earnings release, 10-Q, 10-K) and fiscal period. Use edgar_search with company CIK, form and filing-date filters rather than the question's wording. A Q4 earnings release is filed about 5-6 weeks after quarter end, so filter on that window. If web_search returns nothing, retry once with a short non-empty query (never an empty or null one), then use edgar_search or a known primary URL.
- A search snippet or result title is a lead, not evidence. Open the primary document with parse_html_page (one clear key per document), then ask retrieve_information one targeted question at a time. Use input_character_ranges on long filings. Confirm figure, period, unit and GAAP/non-GAAP basis in the retrieved text.
- parse_html_page cannot read PDFs (annual-report PDFs, ARS). Use the HTML 8-K exhibit or 10-K/10-Q instead.
- Guidance-versus-actual questions need two opened documents: the release for the quarter BEFORE the period judged (it holds the outlook) and the release or filing that reports the period itself. Read the guided range and the actual from those opened documents, not from snippets or transcripts. Prefer a figure the company states for the quarter. If you must derive a quarter by subtracting nine-month from full-year figures, say so and cross-check against a stated figure.
- Compare like with like: same metric definition, same period, same unit. For a ratio guided as a range, take the midpoint of the stated range. Compute the actual ratio from dollar figures at full precision, and also note the company's own rounded stated ratio. If the two bases give different gaps, give the unrounded one as the headline and the other as a labelled alternate. State beat or miss and the difference in the unit the question asks for (bps = percentage-point difference x 100).
- Re-check every figure in the calculation against the retrieved text before submitting. If a parsed table looks garbled, cross-check it against the document's own text.
- Cite only documents you opened and retrieved from. Do not list a filing, PDF or transcript seen only in search results (or opened for nothing), and do not attribute a figure to a document you did not retrieve it from. If a figure came from a snippet only, say so.
- Write the final answer in plain text with no citation markup (no <cite> tags). Give each figure with period, unit and source, then the calculation, then the conclusion. Submit with submit_final_result as soon as the figures are verified.
