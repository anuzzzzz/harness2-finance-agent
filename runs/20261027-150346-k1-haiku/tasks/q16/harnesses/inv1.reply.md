# Tool use

- Decide the document and period before searching: company, form (10-K, 10-Q, 8-K, 424B5 prospectus supplement, EX-99.1), and date window. Use edgar_search with company and date filters, not the question's wording. If web_search returns 0 results, retry once with a short non-empty query (never an empty one), then use edgar_search or a known primary URL.
- A search snippet or result title is a lead, not evidence. Open the primary document with parse_html_page (one clear key per document), then ask retrieve_information one targeted question at a time. For long filings, ask about one topic per call (offering size and price; dividends; conversion; voting; use of proceeds). Confirm each figure's period, unit and share count in the retrieved text.
- parse_html_page cannot read PDFs. Use the HTML filing.
- Security-terms questions (preferred stock, notes, convertibles): the terms live in the final prospectus supplement (424B5) and the 8-K that files the certificate of designations or indenture. Prefer the final supplement over the preliminary one. Where the base offering and an over-allotment option differ, report both and say whether the option was exercised, based only on an opened document. If no opened document shows exercise, say it is unconfirmed.
- Cite only documents you opened and retrieved from. Do not list a press release, news article or mirror seen only in search results, and do not attribute a figure or a fact such as the launch size or exercise of the option to a page you did not open. If a useful fact comes only from an unopened source, either open it or leave it out.
- Write the final answer in plain text. Never paste citation markup such as <cite index=...> tags. State each term with its figure and unit, and name the document it came from. Submit with submit_final_result once the terms are verified in the primary text.
