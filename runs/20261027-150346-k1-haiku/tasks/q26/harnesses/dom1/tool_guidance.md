# Tool use

- Decide the document and period before searching: company, form (10-K, 10-Q, 8-K EX-99.1, proxy) and fiscal period. Use edgar_search with the company's CIK and date filters. If web_search returns nothing, retry once with a short non-empty query. Never send an empty or null query.
- A search snippet or result title is a lead, not evidence, and this holds even when the snippet looks like an exact quote. Open the primary filing with parse_html_page, then ask retrieve_information one targeted question at a time. Confirm the figure, period, unit and basis in the retrieved text before relying on it. parse_html_page cannot read PDFs, so use the HTML filing or exhibit.
- Third-party reproductions (stocklight, statista, stockdividendscreener and similar) are not sources. Use them only as pointers to the filing.
- Cite only documents you opened and retrieved from. Do not list a filing seen only in search results. If a figure came only from a snippet, say so.
- Write the final answer in plain text. Never paste citation markup such as <cite index=...> tags. State each input with its period, unit and source, then the calculation, then the conclusion in the form the question asks for. Round only the final number.
- Workforce and headcount questions: the count is in the 10-K, Item 1 "Human Capital" (employees as of fiscal year-end, usually rounded to the nearest thousand, with a U.S./international split). Use the fiscal year-end date the question names, and match "full-time" to the filing's wording. Treat "internationally" as outside the U.S. only if the filing's split is U.S. plus international, and say so. Compute share = part / total from the filing's own components. Show the total, the U.S. figure and the non-U.S. figure, and note that the filing's rounding makes the percentage approximate.
