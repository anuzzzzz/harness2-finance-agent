# Tool use

- Decide the documents and periods before searching: company, form (10-K, 10-Q, 8-K EX-99.1) and fiscal period. Use edgar_search with the company and date filters (form 10-K, a file-date window), not the question's wording. If web_search returns nothing, retry once with a short non-empty query. Never send an empty or null query. Then use edgar_search or a known primary URL.
- A search snippet or result title is a lead, not evidence. Open the primary document with parse_html_page (one clear key per document), then ask retrieve_information one targeted question at a time. Use input_character_ranges on long filings. Confirm each figure's period, unit and basis in the retrieved text. A successful tool call does not make a figure correct, so re-check every figure against the retrieved text before it enters a calculation.
- parse_html_page cannot read PDFs (annual-report ARS PDFs, for example). Use the HTML 10-K or 8-K exhibit.
- Multi-year trend questions: a 10-K shows only about three years of an operating metric. Plan the filings before searching. Take the latest 10-K for its three years, and the 10-K from about three years earlier for the early years. Where the two overlap, check that the figures agree and say if a later filing restated one. Retrieve one value per year and period, and build a year-by-year table from opened text, not from a summary in a snippet.
- Calculate from the retrieved figures at full precision: absolute change, % change and, for a multi-year span, CAGR (state the number of years). Re-do each calculation once before submitting. Check that each sentence of narrative ("sharp rise", "plateau") matches the computed numbers.
- Enough evidence means every figure in the answer was retrieved from an opened document. Submit with submit_final_result as soon as that holds, and do not use turns on extra searches once it does.
- Cite only documents you opened and retrieved from. Do not list a filing seen only in search results, and do not attribute a figure to a document you did not retrieve it from. If a figure came from a snippet only, say so plainly.
- Write the final answer in plain text. Never paste citation markup such as <cite index=...> tags. State each figure with its period, unit and source, then the calculation, then the conclusion the question asks for.
